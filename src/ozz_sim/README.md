# ozz-salinity-sim

Моделирование защиты силового кабеля соледобывающей плавучей платформы (0,4 кВ)
от утечек тока в воду по способу «напряжение между заземлённой нейтралью и
электродом в озере» при разной солёности воды. Модель построена по расчётной
схеме из диссертации (рис. 2.5–2.6) и воспроизводит рис. 2.7.

## Интерактивная симуляция (Streamlit)
Файл `app.py` — интерактивная симуляция: ползунки ρ воды, переходного
сопротивления, положения электрода, места утечки и тока срабатывания реле;
графики тока вдоль кабеля и зависимости от солёности.

Развёртывание: [share.streamlit.io](https://share.streamlit.io) →
Repository: `<ваш-логин>/ozz-salinity-sim`, Branch: `main`,
Main file path: `app.py`.
